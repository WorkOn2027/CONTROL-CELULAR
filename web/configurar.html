Esto se hace una sola vez. Hace falta para que el control se pueda instalar como app y para usar el giroscopio.
Certificado: revisando…
1Descargá el certificado Descargar certificado
2Instalalo en Ajustes
  1. Abrí Ajustes y buscá «certificado de CA» (con la lupa de arriba).
  2. Entrá a Instalar certificado → Certificado de CA.
  3. Si avisa que es riesgoso, tocá Instalar de todas formas.
  4. Elegí control-celular-ca.crt (está en Descargas).
Según la marca, el camino suele ser Seguridad → Más ajustes → Cifrado y credenciales. Android puede pedirte tener un bloqueo de pantalla (PIN o patrón). Puede aparecer un aviso de «la red podría estar supervisada»: es normal con certificados propios. Este solo sirve para direcciones de tu red de casa, no para sitios de internet.
3Volvé acá
Cuando el certificado esté instalado, esta página lo detecta sola y te lleva al control. Ahí, en el menú ☰, vas a poder instalar la app.
