Control Celular · iPhone

Esto se hace una sola vez. Hace falta para que el control se pueda instalar como app y para usar el giroscopio.
Certificado: …
1Descargá el certificado Descargar certificado
2Instalalo en Ajustes
  1. Usá Safari (en otros navegadores el iPhone no instala certificados). Al tocar Descargar certificado aparece «Este sitio web intenta descargar un perfil de configuración»: tocá Permitir.
  2. Abrí Ajustes: arriba aparece Perfil descargado (o entrá a General → VPN y gestión de dispositivos). Tocá CONTROL CELULAR → Instalar, poné tu código y tocá Instalar otra vez.
  3. Activá la confianza (el iPhone pide este paso extra): Ajustes → General → Información → abajo de todo, Configuración de confianza de certificados → activá CONTROL CELULAR (solo red local).
El certificado solo sirve para direcciones de tu red de casa, no para sitios de internet. Lo podés sacar cuando quieras desde Ajustes → General → VPN y gestión de dispositivos.
3Volvé acá
Cuando el certificado tenga la confianza activada, esta página lo detecta sola y te lleva al control. Para instalarlo como app: en Safari tocá Compartir → Agregar a inicio.
